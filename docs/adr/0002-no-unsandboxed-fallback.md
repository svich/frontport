# No unsandboxed fallback

A Port that can't work inside the sandbox is marked Unsupported and is never offered unsandboxed, not even behind a warning. The sandbox is Frontport's core promise. An escape hatch would turn every compatibility problem into pressure to use it, and the promise would stop meaning anything. So the fix is always in the Port: Catalog launch arguments or a patch in its Recipe. Until then, it stays Unsupported.
